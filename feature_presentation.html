What Changed

From signal trading to portfolio control

02 / 08
[-1, 1] Continuous action space controls target net exposure in [-1, 1].
DSR Differential Sharpe reward replaces simple trade-profit feedback.
Risk Stop-loss, drawdown lock, and volatility scaling are enforced in the environment.
SAC Continuous-control algorithms become first-class training options.

Legacy branch behavior

  • Action is Buy, Sell, or Hold.
  • T+1 rule blocks same-day sell after buy.
  • Reward mostly follows realized trade return.
  • Risk metrics are not part of the environment state.

Feature branch behavior

  • Action is target position ratio.
  • Portfolio state is included in each observation window.
  • Reward optimizes risk-adjusted incremental return.
  • Risk constraints can flatten or reduce exposure.

Algorithm Deep Dive

Reward and risk controls

05 / 08
target_t = clip(raw_action_t * ATR_base / ATR_t, -max_pos, max_pos)
DSR_t = (b * delta_a - 0.5 * a * delta_b) / (b - a^2)^(3/2)
reward_t = sharpe_coeff * DSR_t - dd_coeff * max(0, DD_t) - turn_coeff * |delta position_t|
stop_loss: unrealized_pnl <= -5% -> target position = 0
drawdown_lock: equity drawdown <= -15% -> new exposure is reduced
cost model: transaction_cost = |delta position| * equity * fee_rate

Why DSR

Differential Sharpe converts risk-adjusted performance into a step-level signal, avoiding a reward that only cares about raw upside.

Why penalties

Drawdown and turnover penalties discourage unstable exposure changes that may look profitable in raw return but fail as a portfolio process.
