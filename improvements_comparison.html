Trading Agent Improvements — Before vs After

Continuous position management + trend-aware state space, evaluated against a discrete baseline and Buy & Hold on the same test window.

Initial capital ¥100,000 · Test period 2024-01-02 → 2026-01-09

What changed

Improvement #1

Revise the action space

Discrete buy/sell → continuous target position a_t ∈ [-1, 1]. The agent sizes exposure continuously (RL-based position management) instead of flipping all-in / all-out.

Improvement #2

Upgrade the state space

Four trend-aware features injected into the observation:

  • SMA-20 slope — Rolling slope of the 20-day moving average -> trend direction.
  • Bollinger width — Normalized band width -> volatility / trend-strength regime.
  • ADX — Average Directional Index -> raw trend strength, direction-agnostic.
  • MACD cross — Golden/death-cross regime -> rule-based trading prior.
Improvement #3

Enhance performance indicators

Max Drawdown, Sharpe, Sortino, Calmar, win rate and turnover are computed per episode and reported in the table below.
